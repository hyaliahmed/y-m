# دعوة عقد قران يوسف و مينا

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (Public).
2. ارفع كل محتويات هذا المجلد كما هي إلى جذر المستودع: `index.html` والمجلدات `media` و`audio` و`fonts`.
3. من Settings ثم Pages اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
4. بعد دقيقة أو اثنتين يظهر رابط الدعوة بهذا الشكل: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## تعديلات سريعة داخل index.html
- نص الآية: السطر الذي يبدأ بـ `const VERSE`.
- موعد العدّاد: السطر الذي يبدأ بـ `const EVENT` (التوقيت محسوب على بغداد).
- رابط ويز: ابحث عن `waze.com/ul`.
- لمعاينة أي صفحة مباشرة أضف إلى الرابط `?s=` ورقم الصفحة من 0 إلى 6، مثل `?s=4`.
- لكي تظهر صورة المعاينة عند مشاركة الرابط في واتساب، استبدل `media/t1-start.jpg` في سطر `og:image` بالرابط الكامل للصورة بعد الرفع.

## الخط
كل الصفحات عدا الآية الكريمة مكتوبة بخط Milan Display Swashes (للمصمم عمر حسن)، والملف موجود في مجلد `fonts` كما هو دون تعديل. رخصة الخط تسمح بالاستخدام الشخصي فقط.
